# 消息通知设置面板:状态可见性改进清单(待实施)

来源:三份产品研究之"状态可见性"报告(2026-10-28)裁决为阶段 C,本文档为其唯一交付。实施时逐条认领,不作为一次性任务。

范围:`packages/dsh-turn-notify/src/client.js` 设置面板行为层。文案与结构层已由 833d8ea 完成,不在本清单。

优先级:P0=伤害用户信任,尽快;P1=明显困惑;P2=锦上添花。

## P0

### C1 配置加载失败静默伪装成默认值
- 现状:`api('/api/turn-notify/config')` 的 `catch(() => {})`(TurnNotifyApp 挂载 effect)吞掉失败,面板以 `DEFAULT_CONFIG` 占位值照常渲染,与真实状态零区分;音效列表失败同样静默,显示假空态"还没有上传过音效"。
- 用户困惑:加载失败时改任何开关,提交的是占位值,覆盖真实配置;或误以为"音效全没了"。
- 建议:`configLoaded=false` 时面板骨架化并禁交互;请求失败就地渲染错误条(`tn-field__alert` 样式复用)+ 重试按钮,不进入可编辑态。

## P1

### C2 pill 同形三义
- 现状:三组 pills 视觉完全一致,分别表达"提醒/不提醒"(全局,存服务器)、"出声/静音"(本机)、"轻叮/静音"(本机)。仅行标签与 title 可区分,扫视不可辨。
- 建议:三选一——(a)pill 内嵌通道图标;(b)关态直接显示结果词(如"任务完成·静音");(c)本机 pill 改非品牌色。任一方案均需保持 plugin-ui-design.md 状态色规约。

### C3 依赖失效不可见
- 现状:提示音总开关(KEY_SOUND)关闭后,分类 pills 仍亮仍可点;轻叮依赖 KEY_PAGE_SOUND 与 toast 库双条件,不可用时无解释。
- 建议:下级组在依赖不满足时降透明度 + 禁点 + 就地一行"已被 XX 停用"。

### C4 权限状态无 onchange 监听
- 现状:permission 为挂载/申请时一次性 useState 采样;用户在浏览器地址栏把"拒绝"改回"允许"后面板红字不消失,重开面板才更新。
- 建议:`Notification.permission` 无原生事件,轮询不可取;在面板 `visibilitychange`/`focus` 时重采样即可覆盖绝大多数路径。

### C5 webhook 失焦保存与测试按钮竞态
- 现状:mousedown 先触发 blur(异步保存),click 同步比较未更新的 `config.webhookUrl`,首次点击必报"尚未落盘"。833d8ea 已用 `testWebhookAfterSave` 前置落盘修复主路径,但 `saveConfigFields` 与测试请求仍可能并发(旧 URL 短暂在途)。
- 建议:`testWebhookAfterSave` 等待保存 promise 完成后再发起测试(当前已 `.then(() => testWebhook())`,复核响应竞态窗口即可)。

### C6 乐观回填失败不回滚
- 现状:`setConfigField`(rootsOnly/hostNotify 等全部开关字段)乐观回填,失败仅 toast 不回滚;对照 `toggleFolderRunning`/`toggleImEnabled` 均有回滚,同类三种策略并存。
- 建议:统一为乐观回填 + 失败回滚(toast 消失后开关停在真实状态)。

### C7 测试结果走 6 秒 toast,长诊断读不完
- 现状:系统通知测试的"专注助手拦截"诊断文案质量高但 6 秒消失;测试期间无进度表达。
- 建议:测试按钮两态(进行中/完成),结果就地内联渲染在通道卡内,不自动消失(用户可关闭)。

### C8 生效边界表达不一致
- 现状:HEAD_HINT 说"改动即时生效",但本机后台弹窗两项标注"(存全局)"实际也是即时,侧边栏文件夹项"刷新生效";作用域标注已可见但无统一形态。
- 建议:生效边界统一两种形态:"即时"(默认,不标)与"刷新后生效"(显式标注);存储位置(本机/全局)统一后缀"(本机)"/"(全局)"。

## P2

### C9 通道实时预览行
- 建议:面板头部下方加一行"现在来通知,你会:角落小卡片 + 轻叮一声(不看页面时:系统弹窗 + 提示音)",直接复用 `chooseChannels` + `resolveSound` 同源实时计算,开关点动即刷新。一次性回答状态拼图问题,根治 C3/C4 的大部分用户困惑。实施时注意 chooseChannels 的 client 镜像已在 LOGIC 段,可直接消费。

### C10 denied 恢复指引按浏览器给具体路径
- 建议:按 UA 给 `edge://settings/content/notifications`、`chrome://settings/content/notifications` 等直达路径。

### C11 音量滑块百分比读出
- 建议:滑块旁显示当前百分比,与播放失败提示"音量为 0"可对位。

### C12 IM 页签缺席引导
- 建议:dsh-im 不在场时仍渲染"聊天"页签,内容为引导卡(能力说明 + 安装指引),而非整个页签消失。
