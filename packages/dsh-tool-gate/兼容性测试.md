# dsh-tool-gate 兼容性测试

包定位:全局层工具白名单延迟加载。apply 型单行,inject `tools`,把白名单映射到
全局层各工具 definition 的 `deferLoading` 字段(声明式收敛,undo journal 还原),
机制全部站在宿主 deferred tool loading 原生链路上(deferLoading → API
`defer_loading` → 服务端按需搜索激活)。无 client 半区、无 HTTP 路由、无服务
provide。设计见 [白名单延迟加载-BDD.md](白名单延迟加载-BDD.md)。

## 版本依赖事实

- `deferLoading` 字段与全链路投影(wireSchemas/system-prompt/deepseek 适配器
  `defer_loading`/agent-loop tool-addition 投影)要求宿主 0.2.0-rc.1 起;
  `hostMin = 0.2.0-rc.1`,不为旧版本保留降级分支。
- 侵入面 = ToolRuntime 内部结构 `layers.global.tools`(NamedEntries,data 为
  Map)与 definition 的 `deferLoading` 字段。宿主重构该面即特性检测失败 →
  干净禁用(日志说明零动作),禁用是唯一合法降级形态。

## 测试分层与执行流程

| 层 | 内容 | 手段 |
|---|------|------|
| L1 单元层 | test/ 下 5 个 `*.test.mjs`:收敛决策(converge)、特性检测(registry)、config 管线(config)、行生命周期(lifecycle 假宿主)、官方投影锁定(integration-tools 真 cordis + dsh-tools + dsh-system-prompt) | 包目录 `node --test "test/*.test.mjs"` |
| L2 装载层 | 全包冒烟加载 + 隔离宿主 boot | 仓库根 `node scripts/smoke-load.mjs` + `node scripts/compat/run.mjs` |
| L3 功能面层 | 下节断言全集(6 项) | 真机验证(playwright 或手工) |
| L4 共存层 | 与注册工具的插件(shell-select 双工具、mcp-client 域工具、experimental 工具行)交叉 | 同装验证:白名单外全部打标、白名单内维持全量 |

执行顺序 L1 → L2 → L3 → L4,前层失败即止。

## L3 功能面断言(真机,主测版本)

1. **收敛生效**:行启用后,全局层非白名单工具的 wire schema 带
   `deferLoading: true`(宿主请求日志/会话 request header 可见),白名单内
   工具不带;工具数量不变(可见性不变,只改声明形态)。
2. **白名单热改**:设置页改 `allowlist` 保存 → 无需重启,下一轮请求投影即
   随白名单变化(`loader/volatile-update` 收敛)。
3. **新工具收敛**:启用任一注入新工具的插件 → 该工具自动进 defer 态
   (`tools/change` 收敛),无需重启。
4. **行退场还原**:market 禁用 tool-gate 行 → 全部工具回到注册时原状
   (本包打标消失,被清的自带声明恢复)。
5. **上游退化**:provider 指向不支持 `defer_loading` 的路由 → 请求正常
   (投影层剥字段全量注入),无报错、无行为差。
6. **服务端激活**:DeepSeek Messages 端下,deferred 工具经服务端搜索激活后
   可正常调用(宿主 tool-addition 投影接管,本包零干预)。

## 已知风险与观测点

- `defer_loading` 为 DeepSeek API 未公开文档字段:上游拒收时以断言 5 的退化
  形态呈现(全量注入),不崩;若上游报错则属宿主 llm-deepseek 适配器问题,
  以官方新源码为规范对表,不在本包兜。
- 收敛日志为唯一观测面(`tool-gate: 收敛 defer+N [...] clear-M [...]`),
  排障以启动与 `loader/volatile-update`/`tools/change` 后的该日志为准。
