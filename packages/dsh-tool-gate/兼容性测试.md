# dsh-tool-gate 兼容性测试

包定位:全局层工具白名单延迟加载。主行 apply 型,inject `tools`,把白名单映射到
全局层与全部 per-agent scope 层各工具 definition 的 `deferLoading` 字段(声明式
收敛,undo journal 还原),机制全部站在宿主 deferred tool loading 原生链路上
(deferLoading → API `defer_loading` → 服务端按需搜索激活)。web 行
(`/api/tool-gate/*` 状态读 + 配置写,GUI 唯一配置入口,原生 schemastery 节经
`settings.configure({ auto: false })` 抑制)+ client 半区设置页「工具门」卡片。
无服务 provide。设计见 [白名单延迟加载-BDD.md](白名单延迟加载-BDD.md)。

## 版本依赖事实

- `deferLoading` 字段与全链路投影(wireSchemas/system-prompt/deepseek 适配器
  `defer_loading`/agent-loop tool-addition 投影)要求宿主 0.2.0-rc.1 起;
  `hostMin = 0.2.0-rc.1`,不为旧版本保留降级分支。
- 侵入面 = ToolRuntime 内部结构 `layers.global.tools` / `layers.scoped`
  (NamedEntries,data 为 Map)与 definition 的 `deferLoading` 字段。宿主重构
  该面即特性检测失败 → 干净禁用(日志说明零动作),禁用是唯一合法降级形态。
- web 行 inject `webServer/settings/tools`,服务缺失即行未激活(干净禁用),
  不影响主行收敛本体;client 半区点分声明 `slots` 经 dsh.client.inject 门控。

## 测试分层与执行流程

| 层 | 内容 | 手段 |
|---|------|------|
| L1 单元层 | test/ 下 6 个 `*.test.mjs`:收敛决策(converge)、特性检测(registry)、config 管线(config)、行生命周期(lifecycle 假宿主)、官方投影锁定(integration-tools 真 cordis + dsh-tools + dsh-system-prompt)、web 路由与 GUI 契约(web-ui:faces 投影/守卫 403·405·400/写链路端到端/data-plugin 计数/switch 结构/语法) | 包目录 `node --test "test/*.test.mjs"` |
| L2 装载层 | 全包冒烟加载 + 隔离宿主 boot | 仓库根 `node scripts/smoke-load.mjs` + `node scripts/compat/run.mjs` |
| L3 功能面层 | 下节断言全集(6 项)+ GUI 卡片断言 | 真机验证(playwright 或手工) |
| L4 共存层 | 与注册工具的插件(shell-select 双工具、mcp-client 域工具、experimental 工具行)交叉 | 同装验证:白名单外全部打标、白名单内维持全量 |

执行顺序 L1 → L2 → L3 → L4,前层失败即止。

## 已知风险与观测点

- `defer_loading` 为 DeepSeek API 未公开文档字段:上游拒收时以断言 5 的退化
  形态呈现(全量注入),不崩;若上游报错则属宿主 llm-deepseek 适配器问题,
  以官方新源码为规范对表,不在本包兜。
- 收敛日志为唯一观测面(`tool-gate: 收敛 defer+N clear-M 层 X 白名单 Y 项`),
  排障以启动与 `loader/volatile-update`/`tools/change` 后的该日志为准。
- 真机事故两例(已修复并留 INV):
  - apply 内 ctx.get 即时解析早于服务可达 → inject 声明门控(INV-8);
  - scope 键对象 String 化串层 → 层键用数据表引用(INV-7)。
