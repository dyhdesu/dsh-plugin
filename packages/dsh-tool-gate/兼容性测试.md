# dsh-tool-gate 兼容性测试

包定位:全局层工具白名单延迟加载。主行 apply 型,inject `tools`,把白名单映射到
全局层与全部 per-agent scope 层各工具 definition 的 `deferLoading` 字段(声明式
收敛,undo journal 还原)。原生链路(deferLoading → API `defer_loading` → 服务端
按需搜索激活)之外,2026-10-20 起含**降级折叠**(INV-10):官方 llm-pi-ai 行
adapter 类原型 `streamWithSnapshot` 缝上,不支持 defer 的路由把 deferred 工具
折叠为占位(name 保留 + 占位引导 description + 参数骨架——键名/类型/required,
深剥 description;provider 按请求 tools 集合校验 tool call 名与参数 schema,
剔除会使生成端名字不可见,空 schema 会使模型发空参数),注册 `tool_search`
折叠入口工具(defineTool,隐式白名单)供模型按需检索定义。web 行(`/api/tool-gate/*` 状态读 + 配置写,GUI 唯一配置入口,
原生 schemastery 节经 `settings.configure({ auto: false })` 抑制)+ client 半区
设置页「工具门」卡片。无服务 provide。设计见
[白名单延迟加载-BDD.md](白名单延迟加载-BDD.md)。

## 版本依赖事实

- `deferLoading` 字段与全链路投影(wireSchemas/system-prompt/deepseek 适配器
  `defer_loading`/agent-loop tool-addition 投影)要求宿主 0.2.0-rc.1 起;
  `hostMin = 0.2.0-rc.1`,不为旧版本保留降级分支。
- 侵入面 = ToolRuntime 内部结构 `layers.global.tools` / `layers.scoped`
  (NamedEntries,data 为 Map)与 definition 的 `deferLoading` 字段;降级折叠
  另读 llm 服务内部面 `adapters`/`directory`(Map,gateway 同款判定)与
  llm-pi-ai adapter 类原型 `streamWithSnapshot`(gateway 线上同构缝)。宿主重构
  任一面即该面特性检测失败 → 干净禁用(日志说明零动作),禁用是唯一合法降级形态;
  llm 面失败只损失折叠,打标收敛不受影响。
- web 行 inject `webServer/settings/tools`,服务缺失即行未激活(干净禁用),
  不影响主行收敛本体;client 半区点分声明 `slots` 经 dsh.client.inject 门控;
  主行 llm 面经内部 `ctx.inject(['llm'])` 软依赖。

## 会话隔离检索回归

内存隔离 Cordis + 官方 ToolRuntime/createScope 集成测试覆盖 SC-23/SC-24:
兄弟会话不可互搜私有定义、继承工具可搜、restrict 隐藏项不可搜、同名局部
定义覆盖全局、无 agent 调用仅搜索全局、搜索前后两个会话 schemas 与 defer 态

## 已知风险与观测点

- `defer_loading` 为 DeepSeek API 未公开文档字段:上游拒收时以断言 5 的退化
  形态呈现(全量注入),不崩;若上游报错则属宿主 llm-deepseek 适配器问题,
  以官方新源码为规范对表,不在本包兜。
- 收敛日志为唯一观测面(`tool-gate: 收敛 defer+N clear-M 层 X 白名单 Y 项`),
  排障以启动与 `loader/volatile-update`/`tools/change` 后的该日志为准;
  折叠另有就绪与请求级日志(`tool-gate: 降级折叠就绪(adapter N)` /
  `tool-gate: 降级折叠 -N 工具(名集)`,按名集签名去重)。
- 真机事故三例(已修复并留 INV):
  - apply 内 ctx.get 即时解析早于服务可达 → inject 声明门控(INV-8);
  - scope 键对象 String 化串层 → 层键用数据表引用(INV-7);
  - web 行把裸 tools 服务当层读取器传 faces → readState 每调必抛路由 400
    → web 行同样经 toolLayersOf 投影 + 结构不符跳过路由(INV-9 补注)。
